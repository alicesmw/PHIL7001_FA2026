df = df.rename(columns={

    'What is your age? (in years)': 'age',  # years

})  # end of the {old: new} list; rename() now applies it

Step 3 of 5 · Numbers

Make sure numbers are numbers

  • The form only accepted numbers for shoe size, birth day, height, weight and age.
  • Travel time, favourite number and random number accepted any text, so answers like “30 mins” or “seven” are possible.
  • Python can’t do maths on text: "30" is not 30 (remember "1"+"1"?).

Code

# These answers should all be numbers: make a list of their column names
num_cols = ['shoe_size', 'birth_day', 'height_cm', 'weight_kg', 'age', 'fav_number', 'random_number']
# Turn each of those columns into numbers; anything that isn't a number (e.g. "seven") becomes NaN (missing)
df[num_cols] = df[num_cols].apply(pd.to_numeric, errors='coerce')
# Travel time was free text (e.g. "30 mins"), so pull out the first number in each answer
df['travel_min'] = df['travel_min'].astype(str).str.extract(r'(\d+\.?\d*)', expand=False)
# Turn that extracted text into numbers (careful: "1 hour" becomes 1, so check these answers by eye)
df['travel_min'] = pd.to_numeric(df['travel_min'], errors='coerce')

Step 4 of 5 · Text

Make text answers consistent (optional for today)

  • To Python, "ChatGPT", "chatgpt" and "chatgpt " are three different answers.
  • The RGB question was free text, so answers come in many shapes ("146, 208, 232", "255 0 0", even "blue"). Pulling out the three numbers gives three number columns you can actually use; anything that isn’t three numbers becomes missing instead of crashing the cell.

Code

# Remove spaces at the start and end, and make AI model names lower case ("ChatGPT " becomes "chatgpt")
df['ai_model'] = df['ai_model'].str.strip().str.lower()
# Do the same for colour names, so "Blue" and "blue" count as the same answer
df['fav_color_word'] = df['fav_color_word'].str.strip().str.lower()
# Pull the three numbers out of each RGB answer ("146, 208, 232", "255 0 0", "rgb(255,0,0)") into three new columns
df[['red', 'green', 'blue']] = df['fav_color_rgb'].str.extract(r'(\d+)[,\s]+(\d+)[,\s]+(\d+)')
# Make them numbers; anything that isn't three numbers (blank, "blue", "#92D0E8") becomes NaN (missing)
df[['red', 'green', 'blue']] = df[['red', 'green', 'blue']].apply(pd.to_numeric, errors='coerce')

Step 5 of 5 · Check

Look, then remove impossible or missing values

  • Look at the summary before deleting anything: a height of 290 cm is allowed by the form, but is it believable?
  • Every cut-off is a decision that changes the model. Write down what you removed and why.

Code

# Print a summary of the two columns we will model: look at the count, min and max for odd values
print(df[['shoe_size', 'height_cm']].describe())
# Keep only believable heights (the form allowed 100-300 cm); the cut-off is your decision, so explain it
df = df[df['height_cm'].between(120, 230)]
# Drop any row that has no shoe size, because the model needs both columns
df = df.dropna(subset=['shoe_size', 'height_cm'])

The model · 3 lines

Regression: height ~ shoe size

  • height_cm ~ shoe_size means “predict height from shoe size”: the variable on the left is y, the one on the right is x.

Code

# Fit a straight-line regression that predicts height (y) from shoe size (x)
model = smf.ols('height_cm ~ shoe_size', data=df).fit()
# Print the results table, including the slope (coef), R-squared and p-values
print(model.summary())
# Plot each person as a dot, with the fitted line and its 95% confidence band
sns.regplot(data=df, x='shoe_size', y='height_cm')

In the summary, find

coef on the shoe_size row: how many cm taller, on average, per extra shoe size

R-squared: the share of the variation in height that shoe size explains (0 to 1)

P>|t|: the p-value for the slope

In the plot, find

Each dot is one person. The line is the model’s prediction; the shaded band shows how uncertain that line is.

Try your own variables: change the two column names in the formula and in regplot.
